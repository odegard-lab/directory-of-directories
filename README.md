## Contributing

Found a good directory missing from the hundred? Open a pull request adding it, and propose which entry it should replace.

A few principles:

- Sites must be **alive** and accept new submissions.
- No paywalled link farms or sites that exist purely to resell submissions.
- Keep the format consistent: `| nnn | Site name | <https://url> |`
- The list is hard-capped at one hundred — additions mean removals.

Spotted a site that has died? Open an issue with `[DEAD]` in the title.
